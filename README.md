# Rigol-MHO-Viewer
RIGOL MHO900シリーズの波形をLAN経由で取得・表示するアプリケーションです。

Windows環境で動作します。
pytonをインストールしてinstall_python_packages.batを実行することで必要なライブラリ類をダウンロード・インストールできます。
波形を取得し、詳細に分析したい場合などに便利かと思い作成しました。基本的にAI任せに作成し、デバッグも個人で実施した程度なので
利用した際の責任は一切取りません。その代わり、自由に改変、改造して使用してもらって構いません。
より良いものができたら公開していただけると助かります。
